How a project goes

A five-page site and a full web app go through the same steps. You'll know what's being built, what it costs, and what happens next before we start.

zsh — labs

$ labs new-project --client you

  1. [1/5] intro call we ask a lot of questions and mostly listen
  2. [2/5] scope a written plan: what gets built, the cost, the timeline
  3. [3/5] build you see it working early, not only at the end
  4. [4/5] launch we deploy it, test it, and hand you the keys
  5. [5/5] support fixes and changes once it's live
